## 📊 Разбор методов лабораторной работы №2

### 1. ARIMA модели

**Что делает**:
- Автоматически подбирает параметры (p, d, q) по критерию Акаике (AIC)
- `p` - порядок авторегрессии (зависимость от прошлых значений)
- `d` - порядок интегрирования (сколько раз нужно взять разности для стационарности)
- `q` - порядок скользящего среднего (зависимость от прошлых ошибок прогноза)

**Как работает**:
```python
# Проверяется стационарность ряда
is_stationary = check_stationarity(series)
d = 0 if is_stationary else 1

# Перебираются популярные комбинации
orders_to_try = [(1,d,1), (2,d,1), (1,d,2), (0,d,1), (1,d,0)]

# Выбирается модель с минимальным AIC
best_model = min(models, key=lambda m: m.aic)
```

**Интерпретация результатов**:
- **Низкий RMSE** = хорошее качество прогноза
- **AIC** = критерий качества модели (меньше = лучше)
- **95% ДИ** = ширина доверительного интервала прогноза

### 2. BSTS (Bayesian Structural Time Series)

**Что делает**:
- Разлагает ряд на структурные компоненты:
  - **Уровень** (level) - базовая тенденция
  - **Тренд** - направление изменения
  - **Сезонность** - повторяющиеся паттерны
  - **Случайная компонента** - непредсказуемые изменения

**Реализация в нашем коде**:
```python
model = UnobservedComponents(
    series,
    level='random walk',    # Уровень меняется случайно
    seasonal=None,          # Без сезонности для простоты
    cycle=False            # Без циклических компонент
)
```

**Преимущества**:
- Учитывает неопределенность в параметрах
- Хорошо работает с короткими рядами
- Автоматически обнаруживает структурные сдвиги

### 3. Декомпозиция временного ряда

**Что делает**:
Разделяет ряд на компоненты: `Исходный ряд = Тренд + Сезонность + Остатки`

**Методы в нашей реализации**:

#### a) Полиномиальный тренд:
```python
# Подгоняем полином 2-й степени
poly_features = PolynomialFeatures(degree=2)
model = LinearRegression()
trend = model.predict(x_poly)
```

#### b) Гармоническая сезонность:
```python
# Простая синусоидальная сезонность
seasonal = np.sin(2 * np.pi * t / 365) + 0.5 * np.cos(4 * np.pi * t / 365)
```

#### c) Остатки:
```python
residuals = original - trend - seasonal
```

**Оценка качества**:
- **R² тренда** - насколько хорошо полином объясняет данные
- **RMSE** - точность восстановления исходного ряда
- **Тест нормальности остатков** - проверка, что остатки случайны

### 4. Prophet модель (если доступна)

**Что делает**:
- Аддитивная модель: `y(t) = g(t) + s(t) + h(t) + εt`
  - `g(t)` - тренд (линейный или логистический)
  - `s(t)` - сезонность (недельная, годовая)
  - `h(t)` - праздники и события
  - `εt` - ошибка

**Особенности**:
- Автоматически обнаруживает точки изменения тренда
- Учитывает множественную сезонность
- Робастен к пропускам и выбросам

## 🔍 Анализ результатов по длинам интервалов

### Зачем тестировать разные длины (50, 100, 200, 300)?

1. **Короткие интервалы (50-100)**:
   - Быстрая обработка
   - Могут не захватывать долгосрочные тренды
   - Хороши для ARIMA с малыми p, q

2. **Средние интервалы (200)**:
   - Баланс между скоростью и точностью
   - Захватывают сезонные паттерны
   - Оптимальны для большинства задач

3. **Длинные интервалы (300+)**:
   - Лучше для выявления долгосрочных трендов
   - Требуют больше вычислительных ресурсов
   - Могут переобучаться на коротких рядах

3. **BSTS** - универсальна, но может требовать настройки
4. **Prophet** - отлична для рядов с сезонностью и трендом
