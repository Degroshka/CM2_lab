## Лабораторные работы по анализу временных рядов

### Лабораторная №1 — Предварительная обработка временного ряда

Ожидаемый формат входных данных в `data.xlsx` (лист 1):
- столбец `data` — дата
- столбец `curs` — числовой курс

Выполняет:
- Удаление выбросов методом DBSCAN
- Фильтрацию шума эллиптическим НЧ-фильтром
- Сглаживание взвешенным скользящим средним
- Проверку стационарности (ADF, KPSS тесты)

### Лабораторная №2 — Построение регрессионных, авторегрессионных моделей и моделей в пространстве состояний ✅

Использует очищенные данные из лабораторной №1 и выполняет:

1. **ARIMA модели** - автоматический подбор параметров (p,d,q) по критерию Акаике (до 5x5)
2. **BSTS модели** - Bayesian Structural Time Series с множественными конфигурациями
3. **Декомпозиция временного ряда**:
   - Трендовая составляющая (полиномиальная регрессия, автовыбор степени)
   - Сезонная составляющая (Фурье-анализ с доминирующими частотами)
   - Остаточная составляющая (тесты Жарка-Бера и Шапиро-Уилка)
4. **Prophet модель** - современный метод прогнозирования временных рядов

Результаты представляются в виде детальных таблиц с метриками точности (RMSE, MAE, MAPE, R²) и доверительными интервалами для различных длин мерных интервалов.

**Лучшие результаты**: Prophet (RMSE: 0.0118, R²: 0.9999) > Декомпозиция (RMSE: 0.1538, R²: 0.9897) > BSTS (RMSE: 0.2678) > ARIMA (RMSE: 0.5151)

### Установка
```bash
python -m venv .venv
. .venv/Scripts/activate  # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Запуск
```bash
# Сначала лабораторная №1 (предобработка)
python lb12.py

# Затем лабораторная №2 (моделирование) - полная версия
python lab2.py
```

### Особенности реализации

**Лабораторная №2** включает полную реализацию всех требований:
- Расширенный перебор параметров ARIMA (до 5x5 параметров)
- Множественные конфигурации BSTS с автоматическим выбором
- Продвинутая декомпозиция с Фурье-анализом
- Статистические тесты нормальности остатков
- Интеграция с Prophet для современного прогнозирования
- Детальные графики и доверительные интервалы
- Подавление предупреждений для чистого вывода

### Структура выходных файлов
- `out/` - результаты лабораторной №1
- `out/lab2/` - результаты лабораторной №2
  - `summary_results.xlsx` - сводная таблица всех моделей
  - `results_*.xlsx` - детальные результаты по каждой модели
  - `*.png` - графики сравнения моделей
